## 🆘 PROBLEMAS?

### Script não executa?
1. Certifique-se de estar na pasta do projeto
2. Clique direito → "Executar como administrador"
3. Ou use: `.\git-helper.bat` no terminal

### Git não funciona?
1. Instale: https://git-scm.com/downloads
2. Execute setup.bat novamente

### Firebase não funciona?
1. Instale Node.js: https://nodejs.org/
2. Execute: `npm install -g firebase-tools`
3. Execute: `firebase login`

### Outras dúvidas?
Consulte: **TROUBLESHOOTING.md**
